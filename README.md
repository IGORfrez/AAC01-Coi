## Контрольные вопросы
1:Программа обращается к ос через класс Environment
2:ОС выступает посредником между программой и аппаратной частью компьютера.
3:Это ОС, рассчитаная на работу с 64-битной архитектурой процессора

5:WorkingSet-это обьем физической оперативной памяти, в данный моменты выделенный и реально используемый конкретным процессом.
6:Программа не содержит жёстко заданных значений, а запрашивает актуальные данные у ОС в момент запуска.
